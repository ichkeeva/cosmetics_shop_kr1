# Магазин косметики "Лотос"

Учебный проект по дисциплине **«Фронтенд и бэкенд разработка»** (4 семестр, 2025/2026).  
Реализован в рамках Практических занятий 1–5.

## Стек технологий

- **Бэкенд:** Node.js, Express, nanoid, cors, swagger-jsdoc, swagger-ui-express
- **Фронтенд:** React, Axios, Sass

## Структура проекта

```
project/
├── server/       # Express API
│   └── app.js
└── client/       # React приложение
    └── src/
        ├── api/
        ├── components/
        └── pages/
```

## Функциональность

- Просмотр списка товаров с фильтрацией по категориям
- Создание, редактирование и удаление товаров
- 10 предустановленных товаров (крема, маски, сыворотки и др.)
- Карточка товара: название, категория, описание, цена, остаток на складе, рейтинг
- Swagger-документация с интерактивным тестированием

## Запуск проекта

### Бэкенд

```bash
cd server
npm install
node app.js
```

Сервер запустится на `http://localhost:3000`  
Swagger UI доступен по адресу `http://localhost:3000/api-docs`

### Фронтенд

```bash
cd client
npm install
npm run dev
```

Приложение откроется на `http://localhost:3001`

## Практическая работа №7 – Базовые методы аутентификации

Реализовала серверное приложение с регистрацией и входом:
- Пароли хешируются с помощью `bcrypt`
- Добавлена Swagger-документация

## Практическая работа №8 – JWT-токены

Доработала приложение:
- При входе выдаётся JWT-токен (accessToken)
- Добавлен защищённый маршрут `GET /api/auth/me`

## Практическая работа №9 – Refresh-токены

Реализовала механизм refresh-токенов:
- При входе выдаются два токена: access (15 минут) и refresh (7 дней)
- Маршрут `POST /api/auth/refresh` для обновления пары токенов

## Практическая работа №10 – Хранение токенов на фронтенде

Создала React-приложение с формами регистрации и входа:
- Токены хранятся в `localStorage`
- Axios interceptors для автоматической подстановки токена
- Автоматическое обновление токена при ошибке 401
- Страница профиля с информацией о пользователе

**Реализованные маршруты:**

| Метод | Путь | Доступ |
|-------|------|--------|

| GET | `/api/products/:id` | все |
| POST | `/api/products` | seller, admin |
| PUT | `/api/products/:id` | seller, admin |
| DELETE | `/api/products/:id` | admin |
| GET | `/api/users` | admin |
| GET | `/api/users/:id` | admin |
| PUT | `/api/users/:id` | admin |
| DELETE | `/api/users/:id` | admin |

Реализована middleware `roleMiddleware` для проверки прав доступа.

# 📘 Практические работы №13–17: Frontend & Backend разработка



Данный репозиторий содержит реализацию цикла практических занятий по созданию прогрессивного веб-приложения (PWA) для управления заметками с офлайн-доступом, push-уведомлениями, WebSocket-синхронизацией и напоминаниями.

---

## ✅ Практическое занятие №13 – Service Worker (Базовый офлайн)

**Цель:** Создать основу для офлайн-работы с помощью Service Worker.

**Реализовано:**
- Регистрация Service Worker.
- Кэширование статических ресурсов (HTML, JS) при событии `install`.
- Стратегия `Cache First` для запросов (событие `fetch`).
- Очистка старых кэшей при активации (`activate`).
- Хранение заметок в `localStorage` с возможностью добавления и просмотра.

**Результат:** Приложение полностью работает без интернета после первого визита.

---

## ✅ Практическое занятие №14 – Web App Manifest (PWA установка)

**Цель:** Добавить манифест для установки приложения на устройство.

**Реализовано:**
- Создан файл `manifest.json` с полями: `name`, `short_name`, `theme_color`, `background_color`, `icons` (5+ размеров).
- Подготовлены иконки разных размеров (16x16 – 512x512) с `purpose: maskable`.
- Добавлены мета-теги для iOS (`apple-touch-icon`, `apple-mobile-web-app-status-bar-style`).
- Обновлён Service Worker для кэширования иконок и манифеста.
- Протестирована установка через браузер (Chrome, Edge).

**Результат:** Приложение можно установить как нативное, оно запускается в отдельном окне без адресной строки.

---

## ✅ Практическое занятие №15 – HTTPS + App Shell (Мгновенная загрузка)

**Цель:** Обеспечить безопасное соединение и архитектуру «каркас приложения».

**Реализовано:**
- Настроен локальный HTTPS с помощью утилиты `mkcert`.
- Архитектура App Shell:
  - `index.html` содержит только шапку и контейнер.
  - Контент страниц (`home.html`, `about.html`) подгружается динамически через `fetch`.
- Стратегия кэширования:
  - Статика (App Shell) – Cache First.
  - Динамические страницы (`/content/`) – Network First (с фолбеком на кэш).
- Навигация без перезагрузки страницы (SPA-подход).

**Результат:** Интерфейс отображается мгновенно даже на медленном соединении. Есть страница «О приложении».

---

## ✅ Практическое занятие №16 – WebSocket + Push (Реальное время + уведомления)

**Цель:** Синхронизация заметок между клиентами в реальном времени и базовые push-уведомления.

**Реализовано:**
- Установлены зависимости: `express`, `socket.io`, `web-push`, `cors`, `body-parser`.
- Генерация VAPID-ключей для push-уведомлений.
- Серверная часть (`server.js`):
  - WebSocket-сервер на `socket.io`.
  - Эндпоинты `/subscribe`, `/unsubscribe` для хранения подписок.
  - Рассылка события `taskAdded` всем клиентам.
- Клиентская часть:
  - Подключение к WebSocket.
  - Отправка `newTask` при добавлении заметки.
  - Всплывающее сообщение при получении `taskAdded`.
  - Подписка/отписка на push через `PushManager`.
  - Обработка push-уведомлений в Service Worker (`sw.js`).

**Результат:** Добавленная заметка видна на всех вкладках. Push-уведомления приходят даже при закрытом приложении.

---

## ✅ Практическое занятие №17 – Детализация Push (Напоминания и Snooze)

**Цель:** Реализовать отложенные напоминания с возможностью переноса (snooze).

**Реализовано:**
- Форма добавления заметки с полем `datetime-local` (дата/время напоминания).
- Структура заметки: `{ id, text, reminder, datetime }`.
- Сервер:
  - Хранение активных таймеров (`Map`).
  - Событие `newReminder` от клиента, запуск `setTimeout`.
  - Эндпоинт `/snooze` для откладывания напоминания на 5 минут.
- Service Worker:
  - Обработка `notificationclick` с определением действия `snooze`.
  - Кнопка «Отложить на 5 минут» в уведомлении.
- Обработка ошибок и удаление таймеров.

**Результат:** Можно создать заметку с напоминанием на конкретное время. При наступлении времени приходит push-уведомление с кнопкой «Отложить». Напоминание переносится даже если приложение закрыто.
